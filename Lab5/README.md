В проекте используется абстрактный класс, интерфейс и конкретные классы, объединённые в пакеты.

Абстрактный класс Animal описывает общее поведение всех животных зоопарка. Он содержит абстрактный метод makeSound() и конкретный метод eat(), который наследуется всеми потомками.

Интерфейс Flyable определяет способность летать и реализуется только теми животными, которые могут летать.

Конкретные классы Lion и Eagle наследуются от абстрактного класса Animal.

Класс Eagle дополнительно реализует интерфейс Flyable, что демонстрирует множественное наследование поведения.


Классы распределены по пакетам:

zoo.animals — содержит животных и интерфейсы

zoo — содержит главный класс игры


В главном классе ZooGame демонстрируется полиморфизм, когда объекты разных классов используются через ссылку на абстрактный класс Animal.
