Калькулятор реализует выполнение четырёх базовых арифметических операций: сложение, вычитание, умножение и деление.

На вход программа получает строку вида: 2 * 6.5


Строка разбирается на: первый операнд, арифметический оператор, второй операнд.


После этого выполняется соответствующая операция, а результат выводится в консоль.
