Композиция и агрегация — это виды связи между объектами в объектно-ориентированном программировании.

Агрегация — это отношение «имеет», при котором один объект содержит другой, но не владеет им полностью. Объект может существовать независимо от того, кто его использует.
Композиция — это более жёсткая связь «является частью», при которой один объект полностью владеет другим. Если основной объект уничтожается, его части тоже уничтожаются.

Плюсы агрегации: Объекты слабо связаны; Упрощает повторное использование классов; Повышает гибкость архитектуры; 
Минусы агрегации: Меньший контроль над жизненным циклом объектов; Возможны ошибки при неправильном управлении связями

Плюсы композиции: Чёткое управление жизненным циклом объектов; Более безопасная структура; Проще понимать, кому принадлежат объекты
Минусы композиции: Меньшая гибкость; Сильная связанность классов
