Программа реализует модель колоды карт с основными функциями:
Создание и хранение колоды: 52 карты, каждая карта уникальна (масть + значение).
Перетасовка колоды: метод shuffle() перемешивает карты случайным образом.
Сдача карт: метод deal() удаляет карту из колоды и возвращает её для использования вне колоды.
Возврат карт в колоду: метод returnCard() добавляет карту обратно, контролируя дубликаты.
