Данная программа предназначена для вычисления сложного процента на основе введённых пользователем данных.


Программа поддерживает два режима работы:

Прямое вычисление

По начальному числу, проценту и количеству периодов вычисляется итоговое значение по формуле сложного процента.

Обратное вычисление

По начальному значению, конечному значению и количеству периодов вычисляется процент, необходимый для достижения результата.


Используется стандартная формула сложного процента: S = P * (1 + r)^n  и обратная формула: r = (S / P)^(1/n) - 1


Программа работает с вещественными числами и выводит результат в консоль.
